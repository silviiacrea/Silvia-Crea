Limpieza de páginas obsoletas

Compara las páginas individuales de Catálogo, Especialidades y Trabajos en GitHub con las filas activas de Google Sheets. Primero analiza y muestra qué carpetas sobran; solo después podrás confirmar su eliminación.

    La eliminación se publica directamente en GitHub y no se puede deshacer desde este panel. Se vuelve a consultar Google Sheets justo antes de borrar. Las páginas actuales que sigan activas se conservan.

    Actualizar páginas SEO

    Solicita la regeneración de las páginas individuales de catálogo, especialidades, trabajos y sitemap usando el proceso automatizado de GitHub Actions.

    Actualizar sitemap

    Regenera el sitemap.xml con las páginas SEO y los productos actuales de Google Sheets. También actualiza las fichas individuales para que los cambios de productos se reflejen en el sitemap.

    El proceso se ejecuta en GitHub Actions y publica los cambios automáticamente si termina correctamente.

    Actualizar IndexNow

    Notifica únicamente las páginas nuevas, modificadas o eliminadas desde la última comprobación. El sistema conserva el historial de URL y bloquea nuevos envíos durante 30 minutos; no garantiza la indexación.

    La clave y el sitemap se comprobarán antes del envío. La primera ejecución guardará una referencia inicial sin enviar todo el sitio.
